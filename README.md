# Pixel Cursor Lab

マウスカーソル作成に特化した、ブラウザで動くピクセルアートエディタです。

## 現在の機能

- 16 / 24 / 32 / 48 / 64 px キャンバス
- ペン / 消しゴム / 塗りつぶし / スポイト
- クリック判定位置（ホットスポット）の設定
- Undo / Redo
- グリッド表示・ズーム
- 画像の読み込みとドット化
- 16 / 32 / 48 px の実寸プレビュー
- 作成中カーソルのライブテスト
- PNG 書き出し
- Windows .cur 書き出し
- ブラウザへの自動保存
- Pixel Assistant（現在はローカルルール版）

## 使い方

GitHub Pages などの静的ホスティングでそのまま動作します。ローカルでは index.html をブラウザで開くだけでも基本機能を利用できます。
