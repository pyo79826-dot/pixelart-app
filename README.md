# PixCursor

**PixCursor** は、好きなマウスカーソルをドット絵で手軽に作るためのブラウザアプリです。

公開版: https://pyo79826-dot.github.io/pixelart-app/

## 主な機能

- 16 / 24 / 32 / 48 / 64 px キャンバス
- ペン / 消しゴム / 塗りつぶし / スポイト / 直線 / 四角形
- 左右・上下ミラー描画
- 左右反転 / 上下反転 / 自動中央寄せ
- クリック判定位置（ホットスポット）の設定
- Undo / Redo
- グリッド表示・ズーム
- PNG / JPG / WebP / GIF の読み込みとドット化
- 16 / 32 / 48 px の実寸プレビュー
- 白・黒・格子背景での見え方確認
- 作成中カーソルのライブテスト
- PNG 1× / 4× / 8× 書き出し
- Windows .cur 書き出し
- PixCursorプロジェクトの保存・再読込
- ブラウザへの自動保存
- Pixel Assistant（現在はローカルガイド版）
- PWAインストール対応

## ショートカット

- B: ペン
- E: 消しゴム
- F: 塗りつぶし
- I: スポイト
- L: 直線
- R: 四角形
- H: クリック位置
- Ctrl/Cmd + Z: Undo
- Ctrl/Cmd + Y: Redo
